# Definition of Done — PokéGrading

Una tarea o User Story se considera terminada cuando cumple:

- El cambio está implementado o documentado según el alcance.
- El Pull Request fue revisado por al menos una persona.
- El PR está vinculado al Work Item de Azure DevOps.
- No existen conversaciones sin resolver.
- No se subieron secretos, archivos `.env` ni credenciales.
- El cambio respeta la arquitectura y estándares definidos.
- Se actualizó documentación si aplica.
- Se agregó evidencia de prueba o revisión si aplica.
- El merge se realizó mediante Squash and Merge.
- La rama fue eliminada después del merge.

Para funcionalidades de Sprint 1:

- Registrar cuenta debe respetar el flujo de secuencia aprobado.
- Agregar carta al catálogo debe respetar el flujo de secuencia aprobado.
- Las validaciones definidas en los User Stories deben estar cubiertas.
